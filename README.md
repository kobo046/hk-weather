# 香港天氣卡通手機網站

單一檔案（`index.html`）嘅香港天氣網站，卡通風格、為手機而設計。

## 資料來源
香港天文台開放數據 API（`lang=tc`）：
- `flw`：本港地區天氣預報
- `rhrread`：本港地區天氣報告（即時溫度、濕度等）
- `fnd`：九天天氣預報
- `warnsum`：天氣警告一覽

## 使用方法
下載或 clone 本 repo，用瀏覽器（Chrome／Safari／Edge）直接開啟 `index.html` 即可，毋須安裝任何套件。
